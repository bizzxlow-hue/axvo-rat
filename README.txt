X-NullCat (HP orang tua)
Proyek Android (Gradle). Dibuild otomatis lewat buat-apk.html, atau buka folder ini di Android Studio.
Pasangannya: Jaga Anak (HP anak).
Kontrol jarak jauh: Device, Tambah lewat kode (kode dari Jaga Anak). Database: Firebase Realtime Database, lihat Rtdb.java (alamat) dan firebase-rules.json (aturan).
